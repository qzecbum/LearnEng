# LearnEng
An open source, partially "vibe coded" application to help users learn advanced English communication.
### Features

- **Phrases**
	- Phrases help you learn common English statements that are used in everyday conversations. 
	- Over 100 phrase courses are available in the app.
	- New courses always on the way.

- **Words**
	- Learn new words that can be used for advanced communication.
	- Practice quiz is available for deepening your understanding in the word.
	- Infinite word practice is available to strengthen your memory and understanding of the vocabulary.
	- Over 55 advanced words and more to come.

### App UI/UX
- Smooth Interface with clean animations.
- Consistent buttons and navigation

### Development
- Developed in Android Studio, using Jetpack Compose and Kotlin
